# Day Maringisanwa - Portfolio

A personal portfolio built with React and Vite, featuring an animated binary-wave
background, a glassmorphic panel layout, and a vertical icon sidebar navigation.

Built using:

- React
- Vite
- lucide-react (icons)

## Getting Started

```bash
npm install
npm run dev
```

Open the local URL Vite prints in your browser.

## Build for production

```bash
npm run build
```
